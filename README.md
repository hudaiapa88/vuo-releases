# Vuo for Windows

Download the latest **Vuo-Setup** installer from [Releases](https://github.com/hudaiapa88/vuo-releases/releases/latest).

Vuo lets you control your Windows PC from your Android phone. Install this PC app, then pair it with the Vuo app on your phone.

- Windows 10 or 11 (64-bit)
- Optional drivers (chosen during setup): virtual controller (ViGEmBus) for game mode, virtual display (Virtual Display Driver) for "fit to phone"
